ARAM emballage — حزمة بناء APK من الهاتف فقط
================================================

هذه الحزمة لا تحتوي على APK جاهزة؛ تحتوي على المشروع وإعداد بناء سحابي ينتج APK تجريبية عبر GitHub Actions. لا يلزم تثبيت Android Studio على الهاتف، لكن يلزم اتصال إنترنت وحساب GitHub.

ما الذي تحتويه؟
- نسخة الويب الحالية من ARAM emballage داخل غلاف Android (Capacitor).
- إعداد لمسح الباركود بالكاميرا مع مكتبة ZXing مضمّنة محليًا كبديل عند غياب BarcodeDetector.
- إعداد صلاحية الكاميرا في Android Manifest.
- سير عمل GitHub Actions لبناء APK ورفعها كملف قابل للتنزيل.

طريقة البناء من الهاتف:
1. فك ضغط ARAM_Android_Phone_Build.zip في تطبيق الملفات على الهاتف.
2. افتح github.com من المتصفح وسجّل الدخول أو أنشئ حسابًا، ثم أنشئ مستودعًا جديدًا باسم aram-emballage-android.
3. ارفع ملفات المشروع إلى المستودع مع الحفاظ على المسارات. يجب أن يكون المجلد .github/workflows موجودًا وفيه build-apk.yml. إذا لم يسمح رفع الملفات من الهاتف برفع المجلدات، أنشئ المسارات والملفات من خيار Add file > Create new file في GitHub أو استخدم واجهة رفع تدعم المجلدات.
4. بعد ظهور الملفات في المستودع، افتح تبويب Actions، اختر Build ARAM emballage APK، ثم Run workflow.
5. انتظر انتهاء البناء بنجاح. افتح تشغيل workflow الناجح، ومن قسم Artifacts نزّل ARAM-emballage-APK.zip.
6. فك ضغط ملف Artifact على الهاتف، ثم افتح app-debug.apk للتثبيت. قد يطلب Android السماح بالتثبيت لهذا المصدر.

تنبيهات مهمة:
- هذا يبني APK من النسخة الحالية، ولا يجعل كل الميزات الاحترافية مكتملة تلقائيًا.
- النسخة الحالية تحفظ البيانات محليًا في WebView؛ لا توجد مزامنة سحابية أو نظام مستخدمين وصلاحيات أو تسوية كاملة لديون الموردين بعد.
- ميزة مسح الباركود أُعدّت لكن يجب اختبارها على هاتفك بعد التثبيت ومنح صلاحية الكاميرا.
- قبل إدخال بيانات حقيقية، اختبر البيع والمرتجعات والنسخ الاحتياطي والاسترجاع. احتفظ بملف JSON خارج التطبيق دوريًا.
- هذا Debug APK للاختبار الداخلي، وليس إصدارًا نهائيًا موقّعًا للنشر على متجر Google Play.
